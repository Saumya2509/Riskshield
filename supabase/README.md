# RiskShield — Supabase Cloud Database Architecture

This directory contains the database schema, migration scripts, and architecture documentation for **RiskShield**.

---

## 🗄️ Database Tables Overview

### 1. `reconciliation_runs`
Stores high-level audit summaries for every batch reconciliation run.

| Column | Type | Description |
| :--- | :--- | :--- |
| `id` | `UUID` (PK) | Unique run identifier (`gen_random_uuid()`) |
| `file_name` | `TEXT` | Uploaded CSV or batch name |
| `total_records` | `INT` | Total transactions ingested |
| `exact_matches` | `INT` | Number of Pass 1 Exact matches |
| `fuzzy_matches` | `INT` | Number of Pass 2 Fuzzy fee matches |
| `partial_matches` | `INT` | Number of Pass 3 Partial matches |
| `exceptions_count` | `INT` | Unresolved exception records count |
| `match_rate` | `NUMERIC(5,2)` | Match percentage (e.g. `98.40%`) |
| `cleared_amount` | `NUMERIC(15,2)` | Total value cleared in INR (₹) |
| `open_exception_amount`| `NUMERIC(15,2)` | Total value in open exceptions (₹) |
| `run_time_ms` | `INT` | Processing execution latency in milliseconds |
| `status` | `TEXT` | `COMPLETED` / `PROCESSING` |
| `created_at` | `TIMESTAMPTZ` | Timestamp of execution |

---

### 2. `reconciliation_matches`
Stores individual transaction records, 3-way mappings, variance deltas, and analyst resolution notes.

| Column | Type | Description |
| :--- | :--- | :--- |
| `id` | `UUID` (PK) | Unique record row ID |
| `record_id` | `TEXT` (Unique) | Business transaction ID (e.g. `B1-BNK-001`) |
| `source` | `TEXT` | `BANK` / `LEDGER` / `INVOICE` |
| `counterparty` | `TEXT` | Customer / Vendor name |
| `currency` | `TEXT` | `INR`, `USD`, `EUR`, etc. |
| `invoice_amount` | `NUMERIC(15,2)` | Original invoiced or ledger amount |
| `matched_ledger_id` | `TEXT` | Paired General Ledger ID |
| `delta` | `NUMERIC(15,2)` | Discrepancy amount in INR (₹) |
| `match_pass` | `INT` | `1` (Exact), `2` (Fuzzy), `3` (Partial), `null` |
| `status` | `TEXT` | `Exact`, `Fuzzy`, `Partial`, `Exception` |
| `confidence` | `INT` | AI confidence score (`0–100%`) |
| `exception_code` | `TEXT` | Reason code (e.g. `AMOUNT_MISMATCH`) |
| `explanation` | `TEXT` | Root-cause explanation generated by engine |
| `assigned_analyst` | `TEXT` | Assigned accountant/analyst |
| `is_resolved` | `BOOLEAN` | Resolution state (`true`/`false`) |
| `resolution_notes` | `TEXT` | Audit notes entered by analyst |
| `created_at` | `TIMESTAMPTZ` | Record creation timestamp |

---

## 🔒 Row-Level Security (RLS)
Both tables have RLS enabled with permissive policies for authorized application clients:
- `Allow all operations runs` on `reconciliation_runs`
- `Allow all operations matches` on `reconciliation_matches`

---

## 🚀 How to Apply Schema
1. Open your Supabase Dashboard ➔ **SQL Editor**.
2. Copy the contents of `supabase/schema.sql`.
3. Paste into **New Query** and click **Run**.
